# 六次真实地震案例绘图数据交接

本目录用于把真实记录和已完成的 CompactGRU 单台推理结果交给绘图程序。绘图时直接读取这里的 JSON 和原始记录，不重新训练、不重新滤波、不重新推理，不修改预测数值。

## 目录与路径

```text
数据包根目录/
  events.json                     # 六事件顺序、事件元信息、台站目录索引
  plot_settings.json              # 统一配色、比例、字号、波形纵轴范围
  original_selected_picks.json    # 原始表格标注与最早三个可用台站的选择记录
  provenance_manifest.json        # 数据、模型、预处理来源与校验信息
  map_data/ne_10m_land.geojson     # 本地陆地轮廓；无国界和地形
  YYYYMMDD_event/
    station_1_CODE/
      raw/*.UD                    # 完整Z分量原始记录
      raw/*.NS                    # 完整N分量原始记录
      raw/*.EW                    # 完整E分量原始记录
      inference.json              # 此台站自己的93次流式输出
      waveform_plot.json          # 此台站真实绘图窗口的三分量gal数组
    station_2_CODE/...
    station_3_CODE/...
```

所有 JSON 中可读取的文件路径均相对于数据包根目录；不要按进程工作目录解析，也不要依赖原机器的 `D:` 盘。历史源路径仅用于溯源，不是运行依赖。先读 `events.json`，按其中的事件及台站顺序取文件，不按文件名字母序重排。

## 读取单台预测

`inference.json` 包含记录元信息、真值、模型及预处理说明，以及按时间排序的 `outputs` 列表。每条记录必须恰有 **93** 个输出：

- 名义P后时间：0.32、0.64、…、29.76 s。
- 实际P后时间：保留原H5的采样对齐偏移，不擅自改成名义时间。
- 绝对输出可用时间：与该台触发时刻及实际P后时间对应。
- 震级、震中距（km）、方位角（degree）、原预测sin/cos分量。
- 同一时刻距离和方位角计算出的预测震中经纬度。
- 真实震级、震中距、方位角以及台站和真实震中坐标，独立存放，仅用于画参考线和评分。

使用数据包已保存的处理后推理结果，与既有评估保持一致；不要把原始网络输出与既有裁剪后结果混换，也不要再次裁剪。预测输入来自原始实验的因果100 Hz H5，按32点更新；**不是把下述绘图原始波形重新处理后送入模型**。

方向定义为**从台站指向震中，正北0°、顺时针增加**。若需复核：`azimuth_deg = degrees(atan2(sin_azimuth, cos_azimuth)) % 360`；用WGS84测地正算，起点为台站，距离为预测震中距km×1000。不要加180°，不要用真实震中修正轨迹。优先直接使用JSON里已有的预测经纬度。

## 读取真实波形

`waveform_plot.json` 的 `time_after_p_s`、`Z_gal`、`N_gal`、`E_gal` 数组一一对应。它们由原始记录按头部Scale Factor换算为gal，保留真实采样值，窗口为 **[-3, 29.76] s** 内实际存在的样本，不生成端点、不补零、不复制震前噪声。

绘图使用统一Z分量。这里的物理波形没有归一化、去均值、滤波或任意增益；图中单位写 `Waveform / gal`。原始 `raw` 文件保留完整记录和头部，其正文是整数计数，直接读取时必须乘头部 `Scale Factor`，不能把整数计数当gal。已有 `waveform_plot.json` 可直接画，不再重复换算。

如参考项目的 `load_cases()`：其中 `channels[*]['wave']` 已为旧图显示减去了震前均值，只有加回 `baseline_gal` 才恢复这里的物理幅值。不要把去基线数组误当原始数组。

## 已确认的样图样式

- 单事件一个矩形外框，上下等宽贴合、无间隙：上部轨迹绘图区 **1:1**，下部波形绘图区 **16:9**。
- 上部经度刻度放顶部，直接标 `xx.x°E`；纬度标 `xx.x°N`，不额外写Longitude/Latitude标题。
- 台站黑色三角形，真实震中红色五角星；轨迹线 **0.8 pt**、小预测点，保留全部93点及相邻连接。
- 轨迹及震级共用 **viridis连续渐变**，统一时间归一化0–29.76 s；图例及时间色条放图内。
- 波形用灰色细线，t=0红色竖虚线；震级用右轴、1.5 pt渐变曲线，真实震级红色水平虚线。
- 六事件Z波形左轴统一使用 `plot_settings.json` 的共同物理范围；当前首台样图为 **±1200 gal**。不得每事件独立归一化以放大较小事件。
- 关键轨迹标注用真实已有输出 **2.88、9.92、19.84、29.76 s**。可以写“3 s（实际输出2.88 s）”，不能虚构精确3.00 s输出。
- 使用本地陆海底色与海岸线，不联网；按当地纬度cos修正地理比例，不能直接把经纬度数值等比例理解为物理等比例。
- 白底，Times New Roman/SimSun；轴标签9 pt、刻度和图例8 pt、标题10 pt；导出矢量PDF和600 DPI PNG。

原型代码为项目 `discussion/real_events/plot_one_case_prototype.py`；其读取函数在 `plot_els_event_cases.py`，字体和地理范围函数在 `plot_els_six_single_station.py`，原始读取函数在 `plot_first_waveforms.py`，陆海背景在 `land_background.py`。这些是样式和数据生成的参考；交接包中的数据已准备好，绘图程序可以仅依赖本包JSON。

## 单台与多台严格区分

每个台站目录的 `inference.json` 都是**该台独立预测**。画六事件单台图只取六个 `station_1_*`，不要读此前双台、三台联合定位CSV冒充单台轨迹。

如果后续另做双台、三台融合，必须按绝对输出可用时间对齐，各台只使用当时已经产生的最近输出；接入等待时长与融合方法需另行记录、另存结果。不能把不同台站各自的第3秒直接视为同一个绝对时刻，也不能把融合结果写回本包的单台预测。

导出前检查六事件/台站匹配、原始P版本、每台93点、真实震前3 s、同输出距离与方位配对、统一波形纵轴、轨迹完整性，以及标签/图例/色条无重叠。缺失数据应报告，不生成替代数据。
