# 对比实验的数据准备

## 当前288点制作方案（优先于下方早期准备记录）

按用户最新要求，`build_dataset_288.py` 从原始H5截取288点，并复用 CompactGRU 的首点基线扣除和0.75–40Hz单向SOS滤波，每条记录一次处理整个288点窗口，不按32点分块调用。输出用于 SeisT/MagNet；后续加载器不得重复滤波。详细运行方式见 `BUILD_288.md`。此修改仅编写代码，未执行数据制作。

下文 `prepare_data.py` / `raw_dataset.py` 是早期原始样本层的记录，不代表最新288点输出的滤波状态。

## 已生成的共同样本层

原始制作代码：`dataset/制作所有日本强震数据原始.py`（未修改）。

共同波形源：`dataset/dataseth5/J_K_KIKnet_3000_Raw_100Hz.h5`。
数据为P后30秒、100Hz、Z/N/E、gal；200Hz原记录按固定相位抽取为100Hz。
这不是原始仪器计数，也没有额外抗混叠滤波，按现有数据事实记录。

`prepare_data.py` 生成独立时间戳目录，`data/active_dataset.json` 指向当前版本。
`cohort.npz` 保存有序记录键、标签、划分和P对齐偏移，`manifest.json` 保存来源与校验范围。

沿用 CompactGRU 已有有效样本，不另行随机划分或放宽筛选：

|划分|记录数|原年份规则（key[6:8]）|
|---|---:|---|
|训练|605166|不属于下列验证/测试年份|
|验证|84564|19、20、21、22|
|测试|51772|23、24|

统计单位为波形记录；尚未证明事件级隔离。不把记录名称派生分组自动当成可靠事件ID。
所有选中记录的原始CSV标签与 CompactGRU 标签逐条核对；原始H5抽查12条，未全量扫描原始波形。

## 读取方式

`raw_dataset.RawComparisonDataset(split)` 按清单从原始H5只读、惰性读取，返回 `(3,2976)` 波形及 `[mag, dis_km, azi_deg]` 标签，支持 Windows DataLoader spawn。
`samples` 可限制到已到达前缀；它不做滤波、标准化或模型标签转换。

不复制数十GB波形，不对 CompactGRU 因果H5再次滤波。现有 CompactGRU 权重及其输入预处理保持原样。

## 每个模型的数据处理层（待实现）

共同的是记录身份、真实标签、划分与观测截止时刻，不要求所有方法用相同滤波。
SeisT 与 MagNet 的具体预处理、输入长度、幅值保留方式、标签变换和损失接口尚待按其原实现落实。
不能把上述原始标签直接传给上游损失，也不能宣称当前已生成可直接启动训练的最终模型输入。

早期在线评估时，先截取已到达前缀，再做该模型的窗口处理；均值、标准差及零相位滤波不得提前使用观测截止时间之后的数据。
所有从样本分布拟合的参数只在训练集拟合，验证/测试复用。

## E3WS（等待重新制作）

用户将另行制作包含P前7秒的原始数据。建议保留相同 `file_prefix`、`mag/dis/azi`、Z/N/E、单位、采样率和准确P索引/对齐偏移。
保留P后至少29.76秒以供共同范围比较；按原方法使用整数秒模型时，另明确3、5、10、20秒等实际截止时刻。

禁止为当前P后H5补7秒零值冒充震前记录。新H5就绪后按共同清单精确匹配；缺失记录单独报告，任何三模型共同子集必须重新出清单，并同步评估 CompactGRU。

## 重建清单

```powershell
& "$env:USERPROFILE/.conda/envs/lightweight/python.exe" discussion/model_comparison/prepare_data.py
```

此命令创建新时间戳目录，不启动训练，不修改原始H5。
