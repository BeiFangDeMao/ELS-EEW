# 双台站流式地震预警：验证方案

状态：协议草案，等待事件级数据整理；尚未运行实验，没有生成性能结果。

## 1. 核心问题和可支持的结论

验证：每台运行已有 CompactGRU；只使用某次事件最先触发的两个独立地理台站。
首台持续估计震级、震中距和方位角；第二台可产生输出后，双台估距提供位置约束，粗方位用于候选位置消歧。
全程不加入第三台信息、不重新训练模型，首先研究推理与几何融合。

要回答：在多少事件上、多久之后，可以达到震级绝对误差 <=0.3、震中定位误差 <=20/10 km？
这可以验证双台震源参数估计的精度与时效；还不能单凭这些指标宣称实际用户获得了多少秒的破坏性地震动预警提前量。

以下是待验证假设，不是已知事实：首台在第二台触发时已准确；第二台一秒的方位足以消歧；两台严重方位错误不会同时发生。
两台误差可能相关，镜像候选方位分离角也可能很小，均需用完整事件样本检验。

## 2. 模型与几何口径

- 默认模型：els_eew 的原始 CompactGRU 最佳权重，权重路径见 protocol.json。
- 保持原因果预处理、100 Hz、Z/N/E 顺序、gal 单位，以及原推理钳制范围；不引入整段标准化或双向滤波。
- 每32个新增采样点输出一次，即每台0.32 s一次；每个台站使用独立卷积缓存和 GRU 状态。
- 当前协议各台最多使用29.76 s波形；更长输入的性能属于另一个实验，不能默认外推。
- 震中距标签：Haversine 球面大圆距离，地球半径6371 km；不是包含深度的震源距。
- 方位：由台站指向震中、正北为0度、顺时针，范围[0,360)。
- 位置误差：预测震中与目录真实震中的大圆距离；评估时不做0.01 km舍入。
- 目录真实位置和最终震级只用于事件组织、分层与离线评分，不能参与位置求解或候选选择。

## 3. 数据清单和台站选择

每条记录至少具备：event_id、station_id、record_id、station_lat/lon、原始波形、采样率、
绝对记录起始时刻、标注P到时、目录震中经纬度、目录最终震级；如需震后时间，还需要可靠绝对发震时刻。
建议另保存深度、仪器类别、通道极性/朝向、P拾取来源、数据可用结束时间、原始样本路径。

- 事件按可靠目录ID聚合；不能只按记录名相似、四舍五入震中经纬度或分钟级时间拼接。
- 先固定满足原模型适用域的可用台站池，再按实际/模拟可用触发时刻选最先两台；不是按真实距离选最近两台。
- KiK-net 同一站点 U1/U2 不作为两个独立地理台站；预先固定通道选择规则，不按测试误差选择。
- 时刻并列以固定 station_id 次序决胜；不看结果选台站、不选“最好的一对”、不剔除难以消歧的事件。
- 至少两台的事件进入配对定位评估；少于两台、时刻缺失、第二台在随访结束后才可用等情况单独计数。
- 限定原来的未见测试年份，按事件隔离训练/验证/测试；不要从训练事件中挑几台当作独立测试。
- 使用已有裁剪后数据需确认保留了真实跨台时间差；每条各自把P到时置0并不代表两台同时触发。

## 4. 三套时间轴与无未来信息的回放

记目录发震时刻为 t0，首台和第二台触发时刻为 t1、t2。

1. 震后时间：T-t0，仅在 t0 精度足够时报告。
2. 首台触发后时间：T-t1，作为整段回放的主要统一横轴。
3. 第二台触发后时间：T-t2，作为双台定位时效的主要报告口径。

基线使用人工标注P到时作为理想触发，不包含检测、通信、打包或服务器排队延迟。
有真实触发/数据接收日志时，另做实际可用时刻回放，不能混用两个实验的名称。
人工拾取基线属于离线因果回放，而不是已经验证在线触发性能。

在首台触发后的统一0.32 s网格上输出。时刻 T，各站只读取截至 T 已经到达的样本；
第 i 台采用 k_i=floor((T-t_i)/0.32) 对应的最近一次输出，不能向未来取最近点或插值。
若 k_i<1，该台尚无模型输出。第二台触发本身不立即产生有效双台估计，至少需它的第一个32点块。
统一网格可能再增加不足0.32 s的调度等待，应在结果中说明。

例如第二台触发时，第一台可能已看3.20 s、第二台仅看0.32 s；不能把两台各自的“第3秒”配成同一个时刻。
也不能让首台因果滤波器看到第二台尚未触发时不可能获得的后段样本。

当前协议随访到首台29.76 s输入窗口结束；若第二台触发过晚或波形中断，记录实际随访终点及未达标状态。
不能将最后一个预测无限重复，伪装成输入窗口结束后仍然持续达标。

## 5. 两台定位与方位消歧

### 有两个几何交点时

使用两个预测震中距构造距离约束，得到两个镜像候选位置。
分别计算每个候选位置相对于两台的理论方位，与当前两台预测方位比较，选总圆周角差较小者。
初始版本采用固定等权角差，不在测试集上寻找有利权重。
距离误差和角误差量纲不同，若进一步联合优化，需使用在验证集上固定的尺度参数进行归一化。

不使用真实震中来决定选哪个交点；同时记录候选评分差、两个候选之间的距离、候选方位分离角。
真值只在求解完毕后，离线判断所选候选是否为更接近真实震中的一个。
这属于候选判别正确率，不代表任意情况下都有唯一物理解。

### 不相交、相切、同心/近同心或求解失败时

预测距离有误差，两圆不一定精确相交，不允许只保留相交的好样本。
记录几何状态，并采用预先固定的距离残差稳健拟合和粗方位消歧/约束回退方案。
位置求解沿球面距离实现；若局部投影求初值，最后仍用球面距离检验残差。
回退算法及权重在验证集确定。求解失败、歧义未决保持为未定位，并计入覆盖率，不填真实值。
单独报告“精确两候选可消歧”子集的正确率，和全体配对事件（包括回退）的最终定位达标率。

台站基线过短、两圆近相切、震中远离台站基线时可能病态；需记录并分层展示，不在测试后剔除。
连续性可以作为后续实验；不要将最初错误分支永久锁定，也不要通过平滑掩盖错误跳变。

## 6. 震级输出策略

主基线：全程使用首台的实时震级估计，第二台加入时不直接把不成熟的第二台震级等权平均进去。
这样能明确比较两台定位是否改善，而不同时改变震级融合算法。
附加实验：两台震级等权平均、按可用输入时长或验证集校准误差加权；策略必须提前固定。
不能根据哪一台更接近目录震级，事后挑选该台输出。

## 7. 达标时间：逐事件，而不是总体MAE跨阈值

对于每次事件的系统输出定义：

- eM(T)=abs(M_hat(T)-M_catalog)。
- eL(T)=great_circle(predicted_epicenter(T), catalog_epicenter)。
- 震级阈值 eM<=0.3；位置阈值 eL<=20 km、eL<=10 km。
- 震级从首台首个有效输出开始计；位置从第二台产生有效输出开始计。

每个阈值同时报告：

1. 首次达标时间：第一次落入阈值的输出时刻。
2. 持续达标确认时间：已观察到连续至少2.0 s都在阈值内时的确认时刻；不能回溯为该段开始时刻。
   0.32 s网格上使用实际时间差>=2.0 s（需覆盖至少2.24 s的网格跨度），不以不足2 s的末段充数。
3. 首次达标后又超阈值的比例、首次结果误差和逐时刻误差曲线。

“真实误差是否达标”只能离线评分，线上系统看不到目录真值。
因此达标时间是离线性能指标，不能直接当作线上已经实现的可靠告警判断规则。
若要建立发布规则，应另用验证集校准的置信度或两台一致性指标。

可增加联合条件：同一时刻 eM<=0.3 且 eL<=20/10 km；不能把两个不同时间分别达标当作同时达标。

## 8. 汇总、未达标与比较

主单位是地震事件，每个事件等权；不能把一个事件中几十个台站组合或几千个时间点当独立事件扩充样本。

- 逐阈值统计在1、2、3、5、10 s等时点前首次/持续达标的事件比例。
- 同时报告第二台触发等待时间 t2-t1 的中位数和P90。
- 报告最终平均/中位定位误差、P90、震级绝对误差和对应覆盖事件数。
- 达标时间的中位数/P90若仅在成功事件中计算，必须注明条件并同时给成功率；低成功率时不能写成总体时效。
- 未达标、未定位、第二台未及时到达、数据提前结束均保留原因及随访终点，不从分母静默删除。
- 达标累计比例按全部预定配对事件作分母；短随访另列覆盖率。若做删失分析，必须说明假设及方法。
- 若附加置信区间，以事件为单位重采样，而非以chunk或台站记录重采样。

对照至少包含：

1. 首台独立的距离+方位定位（主对照），与双台在同一事件同一绝对时刻比较。
2. 双台各自单台位置的简单平均（弱融合基线）。
3. 双台距离约束+预测方位消歧（拟议方法）。
4. 真实距离+预测方位、预测距离+真实方位（只作离线诊断，明确不作为可部署性能）。

不引入第三台。可分层分析台站基线、首/第二台到时差、震级、台站至震中距离、P波信噪比，
但需先报告全体事件结果，再解释分层结果。

## 9. 交付文件建议

- events.csv：每个事件一行，目录真值、两台ID、绝对触发时刻、有效截止时间、排除/缺失原因。
- timeline.csv：每事件每输出时刻一行，两台可用输入长度、预测参数、候选/几何状态、融合位置及误差。
- event_metrics.csv：每事件各阈值首次/持续达标时间、未达标/删失原因、随访终点。
- summary.json：事件数、覆盖率、达标比例、条件达标时间统计、误差分位数及配置版本。
- 图：少量代表事件的参数时间序列；全事件按首/第二台时间轴的达标比例曲线。
- 图像沿用 plotting 的中英双版本、宋体/Times New Roman、矢量PDF与600DPI PNG风格。

以上是计划文件名，目前不创建空结果或伪造示例性能。
